Download

下载与安装

GitHub 通道适合逐项获取：直接点击下载按钮即可拉取单个文件，链接稳定、可追溯版本历史， 适合只需要其中一两个工具的场景。
夸克网盘通道适合一次性打包：可以转存整个「vivo刷机工具」目录，避免逐个下载； 单个文件超过 100 MiB 的项目（例如 MiSans Heavy 字体模块）仅在此通道提供。
GitHub 对单个文件设有 100 MiB 的硬性上限，超过该体积的文件无法提交到仓库主干。 这类资源在卡片上会标注「超 100MB」，下载按钮直接指向夸克网盘。
分两种情况：内核模块类（放在 ksu-modules / lsp-modules 目录下）不要解压， 直接在 KernelSU 或 LSPosed 管理器中选中 zip 刷入；工具类（解锁工具、ADB 便携包、紫罗兰工具箱等） 则需要解压后运行。若系统解压失败，可使用资源库中的 7-Zip。
本站提供的文件名已统一规范为 .apk，可直接安装。 如果你的系统仍拦截安装，请在「设置 → 安全 → 安装未知应用」中允许文件管理器安装应用， 并确认下载过程没有中断导致文件损坏。
Unlock & Root

解锁与 Root

如果你只是想体验 Root 权限、临时导出数据或测试某个功能，选临时 Root： 不写分区、重启即失效、不改变解锁状态。如果你需要长期运行内核模块、隐藏 Root 或做主题改造， 则必须走永久解锁路线。两者不冲突，可以先临时验证再决定。
解锁 Bootloader 会改变设备的安全状态，多数厂商会据此调整保修判定， 部分情况下需重新锁回原始状态方可获得正常服务。具体政策以官方售后说明为准——本站无法给出承诺， 请在动手前自行确认并接受这一风险。
先核对两点：① 工具面向 vivo / iQOO 骁龙 9400 平台， 不支持平板设备；② 部分机型要求系统版本在特定范围内。 若机型与版本均匹配仍报错，请检查 USB 驱动是否安装正确、是否以管理员身份运行。
不要立刻拔线或反复重启。保持连接，重新以管理员身份运行工具并选择「继续 / 重试」， 多数现代工具支持断点续做。若设备已进入 fastboot 且无法退出，可长按电源键 15 秒以上强制重启， 再重新进入流程。仍无法恢复时，请使用官方恢复工具或前往售后处理。
Modules

模块使用

只要你想运行 LSPosed 及其模块（主题破解、CA 证书注入等），就必须先安装 Zygisk Next， 它提供 Zygisk API 兼容层。纯内核侧的模块（调度、温控、OTA 阻断）则不依赖它。
两个文件内容完全一致，只是分别放在 KernelSU 模块区与 LSPosed 模块区便于查找。 装一次就够了，重复刷入会造成冲突。
不建议。GPU Governor、线程调度、ExtremeGT、极致性能这几个模块的作用域高度重叠， 同时启用会互相抢夺调度权，轻则效果互相抵消，重则造成卡顿甚至无法开机。 同一层级只保留一个。
移除温控不会改变硬件本身的物理耐受极限，但会让系统不再主动降频保护， 长时间高负载下机身温度会明显升高，进而加速电池老化、影响手感甚至触发热保护关机。 建议仅在明确需要且能接受后果时短期使用，并避免边充边玩。
刷入月虹一键隐藏模块并在其中勾选目标应用，配合 KernelSU 的「隐藏 Root」开关使用。 注意：金融类应用的反检测策略会持续更新，隐藏方案不保证长期有效，请勿将其用于规避合法的风控要求。
Themes

主题改造

看系统版本：低于 15.5.0.1 使用「vivo/iQOO 主题破解 v114514」； 15.5.0.1 及以上使用「主题破解（15.5.0.1 以上版本）」。 版本选错会出现模块加载但功能不生效的情况。
.itz 是完整主题包，可在主题商店的「本地导入」中直接加载； .systemui 是系统 UI 资源文件，需要用 MT 管理器定位到对应路径进行替换。 替换前务必备份原始文件，否则一旦出现异常将难以回滚。
几乎都是系统版本不匹配导致的资源字段对不上。请恢复备份的原版 SystemUI， 确认当前系统版本与主题包适配范围一致后，再重新替换。跨大版本（如 OriginOS 5 → 6）混用资源包必然出问题。
