Capability

从解锁到日常使用的完整链路

六个环节彼此衔接，每一步都有对应的工具与模块支撑，不必再在论坛帖子里拼凑零散资源。

永久解锁 Bootloader

面向 vivo / iQOO 骁龙 9400 平台的一键解锁工具，配套 SakiSU 与 KernelSU 双管理器，解锁后即可写入自定义内核。

免解锁临时 Root

不写分区、不改变解锁状态的提权方案，重启即自动失效。适合先尝鲜验证，再决定是否走永久解锁流程。

KernelSU 内核模块

17 个内核级模块：MiSans 字体替换、GPU 与线程调度、温控移除、OTA 阻断、Root 环境隐藏与系统救援。

LSPosed 主题改造

主题商店破解模块解除机型校验与付费限制，配合 SystemUI 资源替换，实现状态栏到全局外观的自由换装。

环境与驱动就绪

Quick Start

三步完成环境准备

01

安装驱动与 ADB 环境

先安装 vivo 官方 USB 驱动，再解压 ADB 便携包，确保电脑能正确识别设备。

vivo_usb_driver.exe ADB 便携包
02

选择 Root 路线

仅想尝鲜可先用临时 Root；需要长期使用内核模块与主题破解，则走永久解锁 Bootloader 流程。

临时 Root（免解锁） 永久解锁 + KernelSU
03

刷入模块并优化

通过 KernelSU 管理器逐项刷入字体、调度、温控与隐藏模块，再按需替换主题与系统 UI。

MiSans 字体 性能调度 Root 隐藏
